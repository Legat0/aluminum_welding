# Моделирование ванны расплава при сварке алюминия

Численное моделирование электродуговой сварки двух алюминиевых пластин с присадочной проволокой. Цель — связать теплоперенос, течение в ванне и (в следующих версиях) электромагнитные эффекты.

## Структура репозитория

```
aluminum_welding/
├── heat+flow_2d/        # версия 1: 2D тепло + течение + затвердевание (без ЭМ)
├── weldpool_2d_comsol/  # та же постановка в COMSOL Multiphysics 6.2
├── heat+flow_3d/        # 3D полупластина: лаб. СК + weld_pool_3d_moving (окно с дугой)
├── heat+flow+em_3d_axi/ # осесимметричная (r–z) VOF: электрод, капля, ванна, ЭМ в металле
├── heat+flow+em_3d/     # 3D полупластина VOF: движущийся электрод, капля, ванна, ЭМ в металле
├── chen_model/          # Chen 2020: flat 3D-ванна + LTE axi-дуга (I=95 A)
├── refs/
│   ├── weld_pool/       # работы по ванне без сил Лоренца (поверхностный тепловой поток)
│   ├── primary/         # дуга / MHD / GMAW (Murphy, Chen, Bachmann, …)
│   └── others/          # прочие материалы
└── README.md
```

## Версия 1 — `heat+flow_2d`

Двумерная продольная модель монолитной пластины (стык и зазор не разрешаются).

| Включено | Не включено |
|---|---|
| Движущийся гауссов тепловой поток на поверхности | Электромагнетизм / сила Лоренца |
| Жидкая / твёрдая фазы (линейная \(f_L\), зона каши Дарси–Кармана–Козени) | Давление дуги, прогиб свободной поверхности |
| Марангони + плавучесть (Буссинеск) | Присадка / капли / перенос массы |
| Затвердевание после прохода дуги | Полноценный 3D-паспорт дуги |

Плоскость расчёта: \(x\) вдоль шва, \(z\) по толщине. Мощность — **эффективная 2D** (на единицу ширины).

### Запуск

Нужны Python 3 и пакеты: `numpy`, `scipy`, `matplotlib`, Jupyter.

Для коммитов ноутбуков (очистка outputs через git filter):

```bash
pip install -r requirements-dev.txt
nbstripout --install
```

```bash
cd heat+flow_2d
jupyter notebook weld_pool_2d.ipynb
```

В первой ячейке параметров `QUICK = True` — короткий прогон (десятки секунд). Для более мелкой сетки поставьте `QUICK = False`.

Решатель можно вызывать и из скрипта:

```python
from weldpool2d import WeldPool2D, Material, quick_process

model = WeldPool2D(material=Material(), process=quick_process(enable_flow=True))
model.run(record_every=0.05)
```

### Свойства и опоры

Свойства по умолчанию — сплав **Al 5182** (Zhao & DebRoy, 2001). Схема ванны опирается на работы в `refs/weld_pool`:

- He, Fuerschbach, DebRoy — нестационарные тепло/течение, гауссов поток, пористая каша  
- Zhao & DebRoy — алюминий, отрицательный \(d\sigma/dT\)  
- Pitscheneder et al. — роль конвекции (Пекле) в форме ванны  
- Kidess et al. — ламинарная вязкость занижает перемешивание (в v1 без «эффективной» вязкости)

Работы с дугой и ЭМ лежат в `refs/primary` и рассчитаны на следующие версии модели.

## COMSOL 6.2 — `weldpool_2d_comsol`

Та же 2D-постановка (гауссов поток, фазы Al 5182, Марангони, Буссинеск, Дарси) в COMSOL Multiphysics 6.2. Нужны модули Heat Transfer и CFD. Откройте `weldpool_2d.mph` или пересоберите через `build.ps1` (см. README в папке).

## Версия с каплей и ЭМ — `heat+flow+em_3d_axi`

Осесимметричный меридиональный расчёт \((r,z)\) на одной сетке: расходная проволока, рост/отрыв капли (пинч), полёт и удар в ванну со свободной поверхностью (VOF). ЭМ только в металле (аналитический пинч + потенциал в ванне); плазма дуги не моделируется. Горелка неподвижна.

```bash
cd heat+flow+em_3d_axi
jupyter notebook weld_pool_axi.ipynb
```

| Файл | Назначение |
|---|---|
| `weldpool_axi.py` | MAC \((r,z)\), VOF, CSF, Дарси, пинч / \(\mathbf{J}\times\mathbf{B}\), энергия |
| `weld_pool_axi.ipynb` | Постановка, выбор `MeshLevel` (quick/normal/fine), кадры \(\alpha\)/\(T\), шейка |

## 3D с движущимся электродом — `heat+flow+em_3d`

Полупластина \(y\ge 0\): VOF-ванна со свободной поверхностью, вертикальный электрод с ростом/отрывом капли, дуга и проволока едут вдоль шва. ЭМ только в металле; плазма не моделируется. Грубая сетка — демо-прогон, без сравнения с экспериментом. В `QUICK` скорость сварки завышена, чтобы ход электрода был виден за время одного цикла капли.

```bash
cd heat+flow+em_3d
jupyter notebook weld_pool_em3d.ipynb
```

| Файл | Назначение |
|---|---|
| `weldpool_em3d.py` | MAC 3D, VOF, CSF, Дарси, пинч / \(\mathbf{J}\times\mathbf{B}\), движущийся вход проволоки |
| `weld_pool_em3d.ipynb` | Постановка, `QUICK`-прогон, срез \(y\approx 0\), шейка, ход \(x_e\), объём |

## Chen 2020 BOP — `chen_model`

Два уровня для случая **I = 95 A** (Table 1–2):

1. **Baseline без плазмы** — стационарная 3D-ванна (`weldpool_chen.py`): гауссовы BC, усреднённая капля, Лоренц в металле.
2. **LTE axi (ближе к Fig. 7)** — проволока + плазма Ar + ванна + поверхность Kim–Na (`weldpool_chen_axi.py`). Не полный 3D ArcWeld; без паров Al.

```bash
cd chen_model
jupyter notebook weld_pool_chen_axi.ipynb   # LTE-дуга
jupyter notebook weld_pool_chen.ipynb       # flat baseline
```

| Файл | Назначение |
|---|---|
| `argon_lte.py` | Упрощённые таблицы свойств Ar(T) |
| `weldpool_chen_axi.py` | Осесимметричная LTE-дуга + ванна + \(\varphi(r)\) |
| `weld_pool_chen_axi.ipynb` | Прогон 95 A, Fig. 7 / Fig. 5 style |
| `make_figs_axi_95A.py` | Рисунки `fig_chen_axi_95A_*.png` |
| `weldpool_chen.py` | 3D flat-pool baseline без плазмы |
| `results_axi_95A.npz` / `results_95A.npz` | Сохранённые прогоны |
